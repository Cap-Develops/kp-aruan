## Как запустить

### Способ 1: Live Server в VS Code (рекомендуется)
1. Откройте папку `kp-constructor` в VS Code
2. Установите расширение **Live Server** (если ещё не установлено):
   - Нажмите Ctrl+Shift+X
   - Найдите "Live Server" от Ritwick Dey
   - Нажмите Install
3. Нажмите правой кнопкой на `index.html` → **Open with Live Server**
4. Откроется браузер с конструктором

### Способ 2: Прямое открытие в браузере
⚠️ Фотографии могут не загрузиться из-за ограничений безопасности браузера.
Если не работает — используйте Способ 1.

## Как пользоваться

1. **📋 История** — список сохранённых КП, кнопка «+ Новое КП»
2. **1. Клиент** — данные клиента, номер КП (генерируется автоматически), чекбоксы доставка/монтаж/обвязка/командировочные
3. **2. Оборудование** — каталог с поиском и фильтрами, добавляйте через «+»
4. **3. Предпросмотр** — итоговый вид КП, кнопка «Сформировать КП (PDF)»

## Особенности

- НДС 22% уже включён в цены
- Гарантия всегда 12 месяцев
- История КП хранится в localStorage браузера
- PDF генерируется через системную печать (Ctrl+P → Сохранить как PDF)
